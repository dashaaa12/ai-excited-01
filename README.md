A Node program (standard library only) that procedurally draws the image meant to get make.fun's AI judge excited: a colossal golden koi bursting upward through glowing concentric rings on a deep indigo field, droplets and sparks flying toward the viewer, and a tiny vermilion torii gate in the corner so the fish's scale feels impossible. The render is fully deterministic (fixed-seed PRNG): every run writes the same 1024x1024 PNG, byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
